📊 Dataverse Projects Portfolio

This repository contains multiple data analysis and dashboard projects built using Python, Power BI, and Jupyter Notebooks. Each project focuses on solving real-world problems using data-driven techniques.

📁 Project Structure
1. AdPerformance_Dashboard
- Analyzes advertising campaign performance
- Tracks key metrics like CTR, impressions, and conversions
- Built using data visualization tools for insights
2. Cake_Notebook
- Data analysis project focused on cake sales or trends
- Uses Python (Pandas, Matplotlib/Seaborn) for exploration and visualization
3. IPL_Dashboard
- Dashboard analyzing IPL (Indian Premier League) data
- Includes player stats, team performance, and match insights
4. Job_Salary_Predication_Notebook
- Machine Learning project predicting salaries
- Uses regression models
Includes data preprocessing, feature engineering, and model evaluation
5. Sales
- Sales data analysis project
- Tracks revenue, trends, and business performance
- May include dashboards or reports

🛠️ Technologies Used:
- Python (Pandas, NumPy, Scikit-learn)
- Jupyter Notebook
- Power BI
- Data Visualization Libraries
- Machine Learning Models

📈 Key Skills Demonstrated
- Data Cleaning & Preprocessing
- Exploratory Data Analysis (EDA)
- Data Visualization
- Machine Learning (Regression)
- Dashboard Development
- Business Insights Generation

🚀 How to Use
- Clone the repository
- Open the relevant project folder
- Run Jupyter notebooks or view dashboards

📌 Notes
- Each folder represents a standalone project
- Datasets are included where applicable
- Dashboards may require Power BI to view
